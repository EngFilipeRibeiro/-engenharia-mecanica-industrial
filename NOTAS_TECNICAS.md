# Limites técnicos

- O módulo simplificado calcula cinemática e geometria.
- Não possui tabela certificada de potência para A/B/C/D/E/Z/3V/5V/8V: Pr, Kθ e Kℓ devem vir do catálogo do fabricante.
- A quantidade é exibida somente com os três fatores informados.
- O alerta de 137 mm para perfil B é específico da imagem enviada, não uma regra universal.
- O modo automático antigo de perfis SP foi ocultado da interface, não convertido para as novas famílias.
- Outros módulos da versão 7 permanecem no arquivo.
